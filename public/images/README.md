# Images Folder Structure

Place your images in this folder with the following exact names:

## Required Images

1. **logo.png** - Website logo (will appear with business name in header)
2. **lead-consultant.jpg** - Professional photo of lead consultant
3. **testimonial-1.jpg** - First testimonial client photo
4. **testimonial-2.jpg** - Second testimonial client photo

## Image Specifications

### logo.png
- **Format:** PNG with transparent background
- **Size:** 200x80px (or proportional)
- **File Size:** Under 100KB
- **Usage:** Header navigation alongside business name

### lead-consultant.jpg
- **Format:** JPG or PNG
- **Size:** 400x400px minimum (square)
- **File Size:** Under 300KB
- **Usage:** Hero section professional photo

### testimonial-1.jpg & testimonial-2.jpg
- **Format:** JPG or PNG
- **Size:** 150x150px minimum (square)
- **File Size:** Under 100KB each
- **Usage:** Testimonial section client photos

## Upload Instructions

1. Add your 4 images to this folder
2. Ensure they match the exact filenames above
3. The website code is already connected to these image paths
4. Restart your development server to see changes
