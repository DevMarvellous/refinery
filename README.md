# The Refinery Business Consult

A premium one-page website for The Refinery Business Consult, built with React, Vite, Tailwind CSS, Framer Motion, and Lucide-react.

## Features

- **Premium Design**: Dark mode aesthetic with Royal Blue (#002366) primary color
- **Responsive**: Fully responsive design for mobile, tablet, and desktop
- **Smooth Animations**: Framer Motion scroll animations and micro-interactions
- **Modern Stack**: React + Vite + Tailwind CSS + Framer Motion + Lucide-react

## Project Structure

```
src/
├── components/
│   ├── Header.jsx          # Sticky navigation with consultation banner
│   ├── Hero.jsx            # Hero section with CEO image placeholder
│   ├── WhyChooseUs.jsx     # 3-column features grid
│   ├── ConsultationWindow.jsx # Time display and consultation info
│   ├── Testimonials.jsx    # 2-column client testimonials
│   ├── Booking.jsx         # CTA section with gold button
│   └── Footer.jsx          # Simple footer
├── App.jsx                 # Main application component
└── index.css               # Tailwind CSS and global styles
```

## Color Palette

- **Royal Blue**: #002366 (Primary background)
- **Sky Blue**: #87CEEB (Accent borders)
- **Gold**: #D4AF37 (Accent and CTAs)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Sections

1. **Header**: Sticky navbar with daily consultation hours (6PM-7PM)
2. **Hero**: Title, subtext, and CEO image placeholder with gold border
3. **Why Choose Us**: 3-column grid highlighting key benefits
4. **Consultation Window**: High-visibility section with time display
5. **Testimonials**: 2-column layout with client success stories
6. **Booking**: Centralized CTA with gold button linking to Google Form
7. **Footer**: Copyright and subsidiary information

## Key Features

- **Mobile-First**: Responsive design with hamburger menu
- **Smooth Scrolling**: Navigation links with smooth scroll behavior
- **Animations**: Fade-in-up animations on scroll using Framer Motion
- **Professional Tone**: Authoritative yet accessible copy using "We"
- **Premium Feel**: Dark theme with gold accents for exclusivity
